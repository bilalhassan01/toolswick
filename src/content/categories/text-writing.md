# Text & Writing

Writers, students, marketers, and developers all hit the same small text problems: a paragraph in the wrong case, two versions of a document to compare, a headline that needs a clean URL slug, or placeholder text for a design mockup. This collection of 14 text and writing tools fixes those jobs in seconds, right in your browser. Paste your text, get the result instantly, and copy it straight back into your document, email, or website, with no software to install and nothing to upload.

The tools follow the formats writers and developers already rely on. The Markdown Editor works with Markdown, the lightweight markup language used across documentation, blogging, and developer platforms, previewing your formatting live as you type. The Morse Code Translator plays authentic beeps generated with the Web Audio API, so you can hear as well as read the code. Text encoding uses the UTF-8 standard, so accented characters and emoji survive conversion, and Find and Replace supports JavaScript regular expressions for precise pattern matching. Everything is processed locally in your browser, so drafts, emails, and private notes stay on your device.

Start with these popular tools:

- **Text Case Converter** — switch text between uppercase, lowercase, Title Case, camelCase, and more.
- **Markdown Editor** — write Markdown and preview the formatted result in real time.
- **Text Compare** — spot additions, deletions, and matching lines between two documents.
- **Lorem Ipsum Generator** — create standard placeholder text by paragraph, sentence, or word count.
- **Morse Code Translator** — translate English to Morse code and back, with audio beeps.
