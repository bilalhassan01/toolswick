# Developer & Data

Developers, designers, and data handlers spend their days converting, formatting, validating, and encoding information, and this collection of 50 tools covers those daily jobs in one place. Format a messy JSON response, generate a QR code for a link, check whether a password is strong enough, or build the meta tags for a new page, all without installing anything or pasting sensitive data into an unknown website. The tools are built for working developers, but anyone who handles data, runs a website, or creates online content will find something useful here.

Where a job has a recognised standard, these tools follow it. Passwords and UUIDs are generated with the browser's Web Cryptography API, using cryptographic randomness instead of predictable pseudo-random numbers, and UUIDs follow the RFC 4122 Version 4 format. Hashing uses SHA-256 through the same Web Cryptography API, JWTs are decoded according to the RFC 7519 standard, and Data URIs follow RFC 2397. GZIP compression uses the browser's native CompressionStream API, and the Color Contrast Checker tests ratios against the WCAG 2.1 AA and AAA accessibility standards. Everything runs locally, so API keys, tokens, and file contents never leave your device.

Start with these popular tools:

- **JSON Formatter** — beautify, validate, and minify JSON, with syntax errors flagged.
- **QR Code Generator** — create QR codes for websites, text, and contact details.
- **Password Generator** — build strong, random passwords with the length and symbols you choose.
- **SHA-256 Hash Generator** — hash text or verify a file checksum in your browser.
- **UUID Generator** — create cryptographically random Version 4 UUIDs, up to 50 at once.
