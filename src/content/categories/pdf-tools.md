# PDF Tools

PDFs are the standard way to share documents, but editing them usually means paying for expensive software or uploading sensitive files to an unknown server. This collection of 15 PDF tools covers the everyday jobs people actually need: merging reports, splitting out pages, compressing a file that is too large to email, and turning images into a single document. Students, office workers, freelancers, and job seekers can handle all of it here in the browser, with no installation and no account.

The tools are built on two well-established open libraries that run entirely on your device. Most editing jobs, including merging, splitting, rotating, reordering, deleting, and watermarking pages, use pdf-lib, which rebuilds the document in local browser memory. Rendering pages as images and reading document details uses PDF.js, the same rendering engine built into modern browsers. Because the work happens locally, a contract, CV, or medical form never travels to a server, and nothing is added to your files unless you ask for it.

Start with these popular tools:

- **Merge PDF** — combine several PDF files into one document, in the order you choose.
- **Compress PDF** — shrink an oversized PDF so it fits email attachment limits.
- **JPG to PDF** — turn JPG, PNG, and WebP images into a single professional PDF.
- **Split PDF** — extract selected pages or split a document into individual pages.
- **PDF to Text** — pull the readable text out of a PDF and save it as a plain text file.

Pick a tool below, drop in your file, and download the finished document straight to your computer.
