# Image Tools

Editing, converting, and shrinking images used to mean installing heavy software or uploading personal photos to a stranger's server. This collection of 26 image tools brings that work into your browser instead, so designers, bloggers, online sellers, and anyone preparing pictures for the web can get it done in seconds. Whether you are compressing a photo for a job application, resizing a banner for social media, or preparing a passport photo, the tool you need is one click away, with no software to install and nothing to sign up for.

Every tool in this set runs entirely on your device. Resizing, cropping, rotating, and format conversion are powered by the HTML Canvas API, which draws and re-encodes your image in local browser memory, while compression runs through multi-threaded Web Workers so large files process quickly without freezing the page. The EXIF Data Viewer reads camera metadata using the EXIF standard, parsing the same tags your camera embedded, including shutter speed, aperture, ISO, and GPS location. Your files are never uploaded anywhere, so a private photo stays private from start to finish.

Start with these popular tools:

- **Image Compressor** — shrink JPG, PNG, and WebP files for email, websites, and application forms.
- **Image Resizer** — change any image to exact pixel dimensions while keeping its proportions.
- **Convert to WebP** — switch JPG and PNG images to smaller, faster-loading WebP files.
- **Passport Photo Maker** — crop photos to official US, UK, Schengen, and China passport sizes.
- **EXIF Data Viewer** — inspect the hidden camera settings and location data inside a photo.

Because nothing leaves your device, you can work on personal or client photos with confidence, and every finished result downloads straight to your computer.
