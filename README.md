# Toolswick

167 free online tools that run 100% in your browser.

**Live demo: https://toolswick.com**

## What it is

Toolswick is a collection of free tools — PDF, image, text, calculators,
converters, developer utilities, audio, productivity, and time & date —
that run entirely client-side. No sign-up, no uploads, no account.
Your files never leave your device, because there is no backend.

## Tools (167)

- **PDF Tools (15):** Merge PDF, Split PDF, Compress PDF, PDF to Image,
  JPG to PDF, PDF to Text, and more
- **Image Tools (26):** Compress Image, Resize Image, Crop Image,
  Convert to WebP, PNG to JPG, and more
- **Text & Writing (14):** Word Counter, Text Case Converter, Lorem Ipsum,
  Markdown Editor, and more
- **Calculators (46):** Percentage, Age, BMI, Loan, Mortgage, Tax, Tip,
  Scientific, and unit converters
- **Developer & Data (50):** JSON Formatter, Base64 Encoder, Regex Tester,
  QR Code Generator, URL Encoder, CSV to JSON, and more
- **Audio Tools (4)**
- **Productivity (8)**
- **Time & Date (4)**

## How it is built

- Static HTML pages generated by a Python build script from a JSON tool
  registry (`src/data/tools.json`)
- Each tool is client-side JavaScript — no framework, no backend,
  no database
- Pages are served as static files
